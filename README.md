# cpp-linux-LTK-multiplayer-game

A simple multiplayer card game developed in C++ for learning network programming.

## 📌 Notes & Limitations

1. **Platform**: This program is designed to run **only on Linux**. Windows, macOS, and other operating systems are currently **not supported**.
2. **Features**: Only the basic card-playing mechanics are implemented. Heroes and their skills will be added in future updates.
3. **Language**: The in-game language is **Simplified Chinese**.
4. **Multiplayer**: Multiplayer requires all players to be connected to the **same Local Area Network (LAN)**.
5. **Gameplay**: Once all players are connected to the server, the game can start. Detailed instructions will be provided in-game.
6. **Purpose**: This program is primarily for personal study of multiplayer networking. The UI is basic and unpolished, as it lacks graphical design and encapsulation.
